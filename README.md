# 无线麦 · 个人状态栏版

[English](README.en.md)

这是 [HD838A/remote-mic-app](https://github.com/HD838A/remote-mic-app) 的个人精简 fork。它把兼容的小米蓝牙语音遥控器变成 Mac 的无线麦克风和快捷键控制器，只保留实体遥控器路径。

## 特点

- 纯状态栏工具：无 Dock 图标、无常驻主窗口，左右点击状态栏图标都可打开菜单。
- 支持 RC001、RC003、ATVV 语音、HID 按键、断线重连和睡眠唤醒。
- 每个按钮可分别配置单击、双击和长按，支持自定义快捷键、自定义 App 和多遥控器配置。
- 三个紧凑设置页：连接与音频、按键映射、权限。
- 本机日志和登录时启动；不包含手机、Apple Watch、Web、统计、回眸/MCP、宏或应用内更新。

## 要求

- Apple Silicon Mac
- macOS 14 或更高版本
- 使用完整 App 不需要 Xcode 或终端；仅从源码构建时需要完整 Xcode 和网络连接
- 兼容的小米蓝牙语音遥控器（主要验证 RC001 / RC003）

## 安装

将完整的 `SayAll.app` 放入“应用程序”后打开。在“连接与音频 → 在这台 Mac 上设置”里完成蓝牙授权、配对和虚拟麦克风安装。App 已携带 `MiRemoteV 2ch`，点击“安装 / 修复”后由 macOS 请求管理员确认，无需下载驱动或打开终端。健康驱动会保留，修复前备份原驱动，不覆盖其他身份的组件。

以下命令仅供开发者从源码构建和安装：

```zsh
./scripts/install-local.sh
```

脚本会构建并验证 `SayAll.app`，再原子替换 `/Applications/SayAll.app`。如果已安装的 `MiRemoteV 2ch` 驱动健康，会原样保留；缺失或不兼容时，脚本会从固定 BlackHole 提交构建驱动，并在安装前备份旧驱动。安装时 macOS 会请求一次管理员授权。

同名 App 或驱动的 Bundle ID 不匹配时，脚本会拒绝覆盖。后续更新仍运行同一命令，不使用应用内更新。

只构建或临时运行：

```zsh
./scripts/build-app.sh
./scripts/run-local.sh
```

## 使用

1. 打开 SayAll，在“在这台 Mac 上设置”中允许蓝牙访问。
2. 点击“配对遥控器…”，在系统蓝牙中连接 `MI RC` 或小米遥控器。此时 App 暂停自动连接；系统配对完成后，回到 App 点击“继续连接”。2 Pro 通常需要同时长按主页键与菜单键；其他型号以说明书为准。切换电脑时先断开旧 Mac 的蓝牙连接。
3. 点击“安装 / 修复”准备虚拟麦克风。首次设置会自动选择 `MiRemoteV 2ch`；已有音频选择（包括手动停用）会保留。也可选择其他回环设备。按键映射所需的输入监控和辅助功能权限可从同一页授权。
4. 在听写应用中选择同一设备作为麦克风，按住遥控器语音键说话，松开结束。
5. 从状态栏菜单快速切换映射，或打开完整设置修改单击、双击、长按和多遥控器配置。

默认 TV 键短按快速切回上一个 App；长按约半秒呼出系统应用切换栏，松开 TV 后用左右键选择，确定键切换、返回键取消。30 秒无操作会自动取消，断连、睡眠或退出也会释放按键。已有自定义 TV 长按保持不变，可在按键设置中选择或关闭“选择应用”。

应用不会自动修改系统默认输入或输出设备，也不会保存或上传语音。权限缺失、遥控器未连接或音频设备失效时，应用只在状态栏菜单显示警告，不会反复弹出设置。

系统配对、权限和驱动需要在每台 Mac 上配置。系统列表里搜不到时先确认遥控器处于配对模式；系统已连接而 App 未就绪时点击“重新查找”。“复制连接诊断”可复制权限、连接、音频状态及最近日志，无需手动执行命令；诊断只写入本机剪贴板，不自动上传。
