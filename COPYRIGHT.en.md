This project adds:

- a menu-bar-only native SwiftUI/AppKit macOS app;
- CoreBluetooth connection and state management;
- CoreAudio output-device selection;
- IOHID permissions, button reading, and macOS action injection;
- macOS build, test, and local-install workflows;
- a Doubao-compatible MiRemoteV2ch.driver solution built from pinned BlackHole source.
